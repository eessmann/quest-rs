This record describes the implemented OpenQASM 3.1 simulator profile and the
local evidence for its compiler, runtime and optional candidate engines. It is
a dated record; current setup instructions are in the [build guide](../../README.md#build).
A supported mathematical contract does not establish execution on unverified
hardware or platforms.

## Supported semantics

The shared language supports typed scalars and fixed arrays, virtual qubits,
standard and user gates, signed controls, inversion and integer powers,
measurement/reset/barriers, typed I/O, nested structured branches and loops,
nonrecursive mixed subroutines, checked dynamic indices, array references and
explicit alias/mutability admission. Text and Rust-token frontends share grammar
and admission; macro captures execute once. Canonical export retains immutable
structured source, including definitions and control flow.

The [guide feature matrix](../book/src/interfaces.md) records actual interface
coverage. Timing/calibration/pulse constructs, hardware addresses, external
functions, complex classical types, unsupported widths, range slices and
register concatenation produce capability diagnostics. Typed Rust builder
convenience APIs are narrower than the parsed language, with checked admission
for dynamic types. No Cranelift, LLVM JIT or external BLAS dependency is introduced.

Classical integer division, modular fixed-width angles and floating `pi` remain
distinct from ideal `Angle::pi` and rational constructors. OpenQASM `U` retains its
specified scalar phase. The pinned standard-library corrections and independent
fixtures are documented in [phase provenance](../openqasm-provenance.md).

## Verification boundaries

- Semantic admission and independent SSA verification check owned IDs, region
  entries, dominance, branch arguments, initialization, types, interfaces,
  aliases, memory effects and resource limits. Fresh edit IDs alone confer no
  proof. Every transformed SSA program is reverified before publication.
- Classical deduplication excludes quantum occurrences and preserves possible
  traps. Exact quantum passes preserve signed controls, scalar phase, effects
  and explicit ordering. Binary and affine-parity replacements are checked
  algebraically; structured windows exclude dynamic/aliased interfaces.
- Bounded numerical fusion uses ordered operand unions and reports changed
  floating rounding. State-vector and density cost models are estimates of
  native calls, traffic, arithmetic and preparation, not speedup measurements.
- Structured and ideal worker replacements retain owned local certificates,
  source occurrence provenance and ordered interfaces. Failed optional candidates
  retain original regions; explicit synthesis rejects an unmet contract.
- The interpreter is bounded by 10,000,000 steps and 64 frames by default.
  Errors retain the completed quantum prefix, call/loop context and owned source
  reports. Library diagnostics do not read files or install global hooks.

## Certified mathematics

The private `quest-rsgridsynth = 0.2.2-quest.1` fork derives from upstream commit
`ffbf9163d4c4bd1cec04febb04d969c954483c8c`; its archive identity and hardening are
recorded in [HARDENING.md](../../crates/vendor/rsgridsynth/HARDENING.md).
The worker initializes precision before constants, preserves exact dyadic or
rational-pi target identity, bounds search and integers, verifies number-theory
solutions, reverses returned product order and retains every scalar `W` factor.

The independent project verifier reconstructs exact cyclotomic matrices and
bounds target trigonometry with rational outward intervals. Its full matrix
difference bound includes phase. Successful mandatory `1e-12` process fixtures
include Z(pi/4), Z(pi/7), X(-2pi/11), Z(0.17), Z(-0.42) and Y(0.23), with recorded
seeds and reproducible candidates. Signed-control lifting retains the bound.
Removing `W` factors is independently rejected. Upstream residual estimates are
not certificates.

The corrected pi/7 regression contains the actual 322-gate worker sequence,
SHA-256 `74d8dd4ab73b855e9dd6fd8f95d122a1a967d0a1aa017cdee7a24cadd1dc117b`.
An earlier hand-transcribed fixture was invalid and was replaced; it is not
counted as evidence. Both the corrected fixture and fresh worker process pass.

QuiZX `0.3.0` generates candidates only for the bounded initial Clifford+T
profile: at most four qubits, 128 input gates and no extra ancillas. Complete
matrix equality and any recovered eighth-root phase are checked independently.
Trailing SWAP input is expanded before graph conversion to preserve the wire
interface. Extraction failure and unsupported phase are normal rejected
candidates, never phase-insensitive proof.

Approximation reports compose sequential regions and exclusive acyclic branches.
A bounded trace of original verified SSA proves exact rotation multiplicities
through deterministic input-independent loops and calls, using actual captures
and rejecting quantum observations. The trace has a separate one-million-step,
64-frame, 64 MiB analysis budget; exhaustion proves nothing. Other paths retain
local certificates when whole-program reasoning is unavailable. Mathematical
synthesis error and QuEST floating execution residuals are separate quantities.

## Platforms and deployment limits

Linux worker limits use one process per request, an owned process group,
30-second wall time, 512 MiB address space and 64 KiB output. Tests exercise
malformed responses, version/seed mismatches, independent certificate rejection,
timeout, memory exhaustion, inherited pipes and cleanup ownership. Resource
limits are not a filesystem or network security sandbox for an arbitrary hostile
executable; callers supply a trusted worker path and distrust candidate data.

Final Linux executables embed absolute `DT_RPATH`, including indirect CUDA
locations. Installed native libraries are not rewritten. The observed closure
includes libcustatevec, libcublas and libcublasLt. This validates loading on this
host, not GPU numerical execution. MPI, other CPU architectures, Windows/macOS,
cross compilation, sanitizer runs and relocatable bundles remain unverified.
The generated CXX code still produces an upstream GCC `-Wmaybe-uninitialized`
warning; project Rust Clippy policy is unchanged.

The external direct and wrapped executables have SHA-256 identities
`353233ce026fa1cf33730ff6402972f07a6b9cfd02541b83d9ce30bb8b18e3a9` and
`7bc8fd6213c8aed6da9d4af365f80019170ff3af9004ef0a7547c7a64e955a6c`.
Both use `DT_RPATH` rather than `DT_RUNPATH`; neither loader closure has unresolved
entries. This is path-dependency consumer acceptance, not a crates.io publication.

The private fork is excluded from workspace lint ownership; its pinned source
and MIT license remain in `crates/vendor/rsgridsynth`. The root lockfile pins the
worker build.
