# P2 polygonal cylinder: complete snapshot and exact rank

The [fixed geometry export](data/2026-10-06-cylinder-p2/geometry.json) contains
16 triangles around an eight-segment polygonal cylinder. Its outer vertices
lie on the specified represented rectangle. The
[independent verifier](fixtures/quest-cfd/cylinder_p2_exact.py) proves that its
complete BDM2/P1 constraint space has **54 independent velocity coordinates**.
The independently reviewed [snapshot consumer](../../crates/quest-cfd/docs/cylinder-high-order.md)
uses that complete space for original pressure, energy, enstrophy and cylinder
force. These are source, constraint and supplied-state results. They are not a
developed shedding solution or a quantum execution result.

## Geometry and boundary meaning

The export uses `explicit-rectangle-corner-priority-v1`. It retains the actual
binary64 vertices, triangle connectivity, exterior labels and boundary kinds
from the new cylinder source. Its source fingerprint is
`17853273085390264558`; the separate SHA-256 of the exported JSON binds all
3,655 bytes and is checked before parsing.

The geometry is the DFG channel with a polygonal approximation to the obstacle.
The rectangle endpoints use the exact represented binary64 values of `2.2`
and `0.41`, rather than the distinct decimal rationals `11/5` and `41/100`.
The verifier uses `Fraction.from_float` to preserve that distinction. It checks
that every exterior edge outside the cylinder belongs to the exact represented
side named by its label.

There are eight cylinder edges, two inlet edges, four channel-wall edges and
two outlet edges. Velocity is prescribed on the first three groups; the outlet
has prescribed mechanical traction. Outlet normal velocity remains free.
Exact side membership does not establish circular-geometry accuracy. Polygon
refinement, runtime geometric embedding checks and physical refinement are
separate evidence.

## Complete constraint count and proof

Each triangular P2 vector polynomial has 12 coefficients. A normal-trace
polynomial on an edge has three coefficients. Each P1 pressure cell has three
divergence moments.

| Quantity | Count |
| --- | ---: |
| Broken velocity coefficients | `16 * 12 = 192` |
| Interior edges | 16 |
| Prescribed-normal exterior edges | 14 |
| Unconstrained natural exterior edges | 2 |
| Normal-trace constraint rows | `3 * (16 + 14) = 90` |
| Cell divergence rows | `16 * 3 = 48` |
| Total rows and proved rational rank | 138 |
| Complete kernel dimension | `192 - 138 = 54` |

The checker assembles Cartesian monomials with exact rational edge normals,
endpoint/midpoint evaluations and volume moments. It imports only elementary
verification routines from the [fixed affine checker](fixtures/quest-cfd/affine_exact.py),
and does not call production CFD or MathCore assembly.

All rational denominators are invertible modulo the independently verified
prime `1,000,000,007`. Modular elimination finds 138 independent rows; a second
elimination of the selected square minor gives determinant `474259756` modulo
that prime. The rank lower bound therefore meets the row-count upper bound.
Every divergence row remains, with no closed-domain pressure-row removal.

The Cartesian and nodal P2 velocity bases span the same space on each
nondegenerate triangle. Replacing P1 Cartesian pressure tests by barycentric
tests is also invertible, as are nonzero normal scalings and orientations.
Consequently this proof concerns the complete mathematical discretization on
the represented source coordinates. It does **not** prove the exact rank,
conditioning or error of the rounded binary64 matrix produced by Rust.

Independent review reproduced the ordinary and optimized runs, compared all
26,496 rational entries against a separately assembled Cartesian/moment oracle,
and obtained rank 138 using a separate modular elimination with reversed column
order. Those checks validate this fixed proof; they are not physical or runtime
acceptance claims.
