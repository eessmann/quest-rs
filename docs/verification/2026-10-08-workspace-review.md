# Workspace quality review ledger — 2026-10-08

This ledger records a bounded review of all 23 workspace packages against the approved
[workspace quality plan](../plans/2026-10-08-workspace-quality.md). It is not a claim that every
invariant or platform has been proved. Paths below are repository-relative. Production
consolidation deliberately leaves independent mathematical verifiers, reference calculations,
and domain-specific resource meanings intact.

The inspection covers public admission and ownership, arithmetic or source semantics,
allocation and failure boundaries, duplication, and lint/test policy. A no-change decision
means the named inspected boundary had no demonstrated defect requiring a change in this
work package; it does not certify the rest of that crate. All first-party Rust targets inherit
`unsafe_code = "deny"`; the audited CXX/MPI FFI exception remains confined to `quest-sys`.

## Consolidation boundaries

- The gate registry drives mechanical mappings, including names consumed by QASM export.
  Numeric matrices, exact verifier gates, source typing and certificate oracles are not generated
  from that same table.
- Shared native multiprecision operations preserve directed rounding and guard digits. Sharing
  these primitives does not make a production QSP synthesis result its own certificate.
- CFD storage helpers do not introduce one universal budget: geometry work, state capacity,
  reference scratch, physical normalization and quantum resource estimates retain different meanings.
- RK4 drift callbacks still return their own vectors. The reusable buffer removes intermediate
  allocations; it is not an allocation-free integrator claim. Retained callback capacities are audited.
- VM quantum effects completed before a backend failure remain observable. Compiler candidates
  retain leases/evidence until accepted publication; work exhaustion and interruption remain outcomes.

## Verification record and limitations

The consolidation command logs are local artifacts under `target/consolidation-*.log`; they are
not benchmark result files. Commands use the installed dependencies, a serialized build lock,
a user systemd scope with `MemoryHigh=24G` and `MemoryMax=28G`, four build jobs and a disk-backed
workspace temporary directory. A source lint warning from the nightly generic-const-expression
trait-solver fallback is recorded separately from Clippy errors.

The final work-package report records completed focused test counts and Clippy/format results.
Full-workspace default/all-feature tests, doctests, release scale checks, generated binding
freshness, installed consumers and native execution are integrated by the parent work package.
Their completion must be established by their own reports. Likewise the benchmark campaign
must retain every expected terminal row before publishing its completion marker; this ledger
makes no speedup, successful-performance-coverage, or full campaign completion claim.
