# Full-DG KvN and distributed QSVT implementation

The user approved implementation of this plan on 2026-10-04. Baseline: 77ae6879dfd3245bee78fe5d9a122f4a2ae6b95c.

## Binding requirements

Implement incompressible BDM/P DG -> exact full constraint elimination -> nonlinear KvN -> global DG history -> coherent block encoding -> QSVT inverse -> observables. Retain all independent physical DG degrees; no reduced models or classical nonlinear/QSVT substitution. Mass weighting, pressure constraints, boundary lifting, configuration truncation and all normalization factors are explicit. Schrödingerisation is a documented future comparison.

Provide 2D and 3D Taylor–Green, lid-driven cavity and cylinder shedding definitions, classical references, full lifted resource estimates and budget-admitted quantum execution. Resource estimates and rejected runs never count as solved benchmarks. Frozen case manifests specify geometry, Reynolds convention, boundaries, time windows and observables.

Reusable layers must support canonical sparse CSR/CSC, compact logical projectors, owning replayable coherent oracles, structured encodings, weighted-matching sparse encodings, spectral-evidence-aware reciprocal solves and arbitrary-width resource accounting. Sparse storage, matrix dilation, circuit stream and statevector must not be globally replicated on the distributed route.

Distributed execution requires sharded immutable input, bounded forward/adjoint gate replay, CPU/MPI kernels for the identical whole matching unitary, checked native ownership/lifetimes, local state initialization, bounded send/receive scratch and collective failure handling. Preserve existing execution routes. Prove fused/gate equivalence including failure sectors and controls.

## Tasks and ownership boundaries

1. Sparse numerics and compatible I/O: validated storage, deterministic duplicates, iterators, adjoint, sparse operations, bounds, serialization integration and tests.
2. Compact logical spaces: ancilla bit constraints and logical ranges, coherent reflections, native projection preparation and bounded materialization tests.
3. CFD foundation: full BDM1 two-triangle periodic assembly, exact full constraint chart, convection/SIP operators, pressure reconstruction, six case manifests and arbitrary-width resource admission.
4. Coherent encodings: structured arithmetic and sparse matching plans, reversible completion, bounded replay, normalization/error/resource metadata, portable control and adjoint semantics.
5. Runtime and MPI: safe local native adapters, immutable sharded descriptors, fused matching execution, local initialization and reductions, collective tests and capped-memory probes.
6. KvN/history/solve integration: weighted configuration DG, global causal DG time assembly, RHS preparation, reciprocal QSVT, observables and same-model trajectory/reference comparisons.
7. Verification and documentation: independent reviews, meaningful targeted tests, workspace/all-feature checks, native provenance and explicitly pending multi-host acceptance.

## Acceptance

Test constraint rank, pressure gauge, conservation, manufactured solutions and independent refinement; extracted encoded blocks and whole unitaries; portable/fused controlled and adjoint equivalence; full-DG KvN against identical ODE trajectories; 1/2/4/8 ranks and split communicators; malformed shards and bounded failure termination; bounded memory/large counts; workspace tests, Clippy, formatting, binding freshness and native MPI compatibility. Real multi-host capacity and scaling remain open until hardware is available.
